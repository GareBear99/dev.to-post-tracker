## Publishing flow

1. Open DEV.to.
2. Create a new post.
3. Paste the Markdown file contents.
4. Preview the post.
5. Keep `published: false` while drafting.
6. Change to `published: true` or click Publish when ready.
7. After publishing, copy the final public URL into your external tracker or post log.

## Safety

Do not store DEV.to API keys in this repo. Use environment variables only, then revoke exposed keys after the posting session.
